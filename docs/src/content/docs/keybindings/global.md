---
title: Global Keybindings
description: Global keybindings available throughout gh-dash.
---

These keybindings are available in all views.

| Key | Action |
| --- | --- |
| `?` | Toggle help |
| `q` / `ctrl+c` | Quit |
| `[` | Previous view |
| `]` | Next view |
| `/` | Start search (where supported) |
| `Esc` | Cancel / close |

View-specific keybindings are documented on their respective pages.
